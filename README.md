# project_ck_machine_learning

## Ghi chú cho báo cáo Việc 6

Random Forest ở Việc 6 chỉ là mô hình minh họa để kiểm tra pipeline tiền xử lý và khả năng dự đoán. Đây không phải mô hình cuối của đồ án. Mô hình cuối được chọn ở phần huấn luyện và đánh giá riêng; không dùng kết quả Random Forest minh họa để kết luận hiệu năng cuối.
