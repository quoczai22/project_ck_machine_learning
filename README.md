# project_ck_machine_learning

## Ghi chú cho báo cáo Việc 6

Random Forest trong phần demo pipeline Việc 6/8 chỉ dùng để minh họa tiền xử lý và khả năng dự đoán. Đây không phải mô hình cuối của đồ án. Việc 6 đánh giá bằng 5-fold CV trên Train. Code Việc 8 có tính chỉ số trên Test, nên nhóm phải ghi nhận Test đã được xem ở bước đó; không dùng chỉ số demo để chọn hoặc kết luận hiệu năng mô hình cuối.
